3 The threat

Description

P7 caches order summaries returned over F19 in a shared retrieval cache keyed by conversation ID. When a conversation ID is reused or guessed, P7 answers from another customer's cached summary instead of making a fresh lookup scoped to the authenticated customer.

Attack scenario

A signed-in customer starts a chat, then replays an older conversation ID taken from a shared support link. P7 finds a cache hit and returns the previous customer's order summary, including the delivery address and the last four digits of the payment card. No error appears and no lookup reaches P3, so nothing is logged in D5.

Attack path

Direct: E1 → P2 → P7 over F18, cache hit inside P7.
